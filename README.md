# Arkan AI Solutions — Landing Page

Arabic-first (RTL) marketing site for Arkan AI Solutions. Outcome-first
positioning: *Arkan turns fragmented operations into reliable, AI-enabled
business systems.*

- **Stack:** React 19 + Vite 7, `motion` for animation, no CSS framework
  (hand-authored design tokens in `src/styles/`).
- **Languages:** Arabic (default) + English, switchable at runtime with full
  RTL/LTR handling. Arabic-first SEO in `index.html`.
- **Themes:** Dark (brand default) + light, with a pre-paint boot script so the
  first frame is already on-brand (no flash).

## Run & build

```bash
npm install        # install dependencies
npm run dev        # dev server → http://localhost:5173
npm run build      # production build → dist/
npm run preview    # serve the production build locally
```

The production output is a fully static `dist/` — deploy it to any static host
(Netlify, Vercel, Cloudflare Pages, S3+CloudFront, nginx). No server runtime.

## Environment variables

Copy `.env.example` → `.env` and fill in. Every variable is optional **except
the lead webhook**, which the form needs in order to submit.

| Variable | Required | Purpose |
|---|---|---|
| `VITE_LEAD_WEBHOOK_URL` | **Yes (prod)** | HTTPS endpoint that receives lead submissions (POST JSON). If unset, the form does **not** fake success — it shows an honest error and offers WhatsApp/email fallback. |
| `VITE_SITE_URL` | No | Public site URL for canonical/OG (default `https://arkan.ai`). |
| `VITE_WHATSAPP` | No | WhatsApp number, digits only, international format. |
| `VITE_EMAIL` | No | Contact email. |
| `VITE_CALENDAR_URL` | No | Booking link (Google appointments, Cal.com, Calendly…). |
| `VITE_PLAUSIBLE_DOMAIN` | No | If set and the Plausible script is present, events are sent. |

> ⚠️ `.env` is git-ignored. `VITE_*` values are **inlined into the public
> bundle at build time** — never put secrets here. The webhook URL is public by
> design; protect the endpoint itself (e.g. accept only the expected payload,
> rate-limit, validate on the server side).

## Lead webhook

On submit the form sends `POST application/json` to `VITE_LEAD_WEBHOOK_URL`.
Success is **only** a `2xx` response — anything else surfaces an error to the
user and keeps their answers (a draft is held in `sessionStorage`).
A 15 s timeout aborts the request.

Payload shape:

```jsonc
{
  "source": "arkan-landing",
  "submittedAt": "2026-06-11T12:00:00.000Z",
  "page": "https://arkan.ai/",
  "language": "ar",
  "leadSource": "hero",          // which CTA opened the form
  "name": "…",
  "company": "…",
  "email": "…",
  "phone": "…",                  // optional
  "industry": "…",               // optional
  "goals": ["…"],                // ≥1, required
  "systems": ["…"],              // optional
  "bottleneck": "…",             // optional
  "contactPref": "…",            // optional
  "timing": "…"                  // optional
}
```

Recommended endpoint: an **n8n Webhook** node set to *Respond immediately* with
`200`. A honeypot field (`website`) is stripped client-side; genuine humans
never populate it.

## Before going live — owner checklist

These are placeholders / claims the **business owner must confirm or replace**:

1. **Production webhook URL** — set `VITE_LEAD_WEBHOOK_URL` to the real lead
   endpoint. (Local `.env` currently points at a test echo endpoint.)
2. **Canonical domain** — `index.html`, `sitemap.xml`, `robots.txt` and the
   structured data all use `https://arkan.ai/`. Replace if the final domain
   differs.
3. **Analytics** — set `VITE_PLAUSIBLE_DOMAIN` (and include the Plausible
   script) or wire `window.dataLayer` to GTM. No analytics ID is hard-coded.
4. **Results metrics** — the figures in the *Results* and *Hero proof* sections
   (e.g. 40,000+ contacts, 99.7% availability, ~2.4 s response, 19 workflows)
   must be confirmed as accurate before publication. Client names are
   intentionally shown as "available on request".
5. **Contact details** — confirm WhatsApp number, email and calendar link.
6. **Open Graph image** — `public/og-image.png` (1200×630) is generated by
   `scripts/make-og.ps1` (Windows / System.Drawing). Re-run if branding copy
   changes: `powershell -ExecutionPolicy Bypass -File scripts/make-og.ps1`.
